# ADR 0001: Modular Monolith

- Status: Accepted
- Date: 2026-08-26

## Context

محصول در مرحله کشف و یک تیم کوچک است. دامنه‌ها هنوز در حال یادگیری‌اند و تراکنش بین import، version و approval مهم خواهد بود.

## Decision

یک FastAPI deployable با ماژول‌های دامنه جدا ساخته می‌شود. مرزها با dependency rule و تست حفظ می‌شوند.

## Consequences

- توسعه، تست و استقرار ساده‌تر است.
- تراکنش و تغییر schema هماهنگ باقی می‌ماند.
- نیاز به قرارداد شبکه داخلی و عملیات چند سرویس حذف می‌شود.
- اگر فشار واقعی ایجاد شد، یک ماژول می‌تواند بعداً جدا شود.

## Rejected

میکروسرویس از روز اول به دلیل هزینه عملیاتی، latency، consistency و مرزهای دامنه اثبات‌نشده رد شد.
