# ADR 0002: Integer IRR Money

- Status: Accepted
- Date: 2026-08-26

## Context

در ایران ریال و تومان در فایل‌ها مخلوط می‌شوند. float نیز خطای گردکردن ایجاد می‌کند.

## Decision

تمام مبلغ‌های canonical با integer ریال ذخیره می‌شوند. currency برابر IRR است. تومان فقط در adapter ورودی/نمایش آینده تبدیل می‌شود و در برش فعلی رد می‌شود.

## Consequences

- محاسبه مبلغ قطعی و قابل ممیزی است.
- واحد در API و UI همیشه روشن است.
- تبدیل تومان باید صریح، تست‌شده و ثبت‌شده باشد.
